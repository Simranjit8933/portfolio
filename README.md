# SIMRANJIT – Personal Portfolio


# Description
A modern, responsive portfolio showcasing my skills, projects, and contact information. Built with **HTML, CSS, JavaScript, and React**, featuring dark mode, smooth scroll animations, and a clean, professional design.

## Features
- **Home Section:** Introduction with typing effect.
- **About Section:** Personal info and skills (Frontend, Backend, Databases).
- **Projects Section:** Display projects with images, descriptions, and links.
- **Contact Section:** Contact form and social media links.
- **Dark Mode Toggle:** Light/dark theme support.
- **Responsive Design:** Works on desktop, tablet, and mobile.
- **Scroll Animations:** Smooth reveal effects.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React
- ScrollReveal.js
- LocalStorage for dark mode
- Netlify / GitHub Pages for deployment
